# 📊 Achieving Abilities – Social Media Performance Analysis (R)

This project analyzes social media performance for **Achieving Abilities LLC**, a nonprofit organization supporting children with autism.  
The analysis focuses on **Instagram** and **Facebook** data, comparing audience growth, posting cadence, and engagement patterns across two time periods (P1 → P2).

---

## 🔍 Project Objectives
- Measure changes in audience visibility across platforms  
- Compare posting cadence and content performance  
- Identify patterns in engagement and traffic  
- Support the organization’s digital strategy with data-driven insights  

---

## 🛠️ Tools & Technologies
- **R**  
- **tidyverse** (dplyr, ggplot2, stringr)  
- **Data Cleaning & Transformation**  
- **Custom Visualizations**

---

## 📈 Key Work
- Cleaned Instagram & Facebook performance datasets  
- Created custom R visualizations using **ggplot2** including:  
  - Bar charts  
  - Line charts  
  - Donut charts  
  - Lollipop charts  
  - Period-comparison trend plots  
- Analyzed audience growth and engagement patterns  
- Compared posting cadence impact between P1 and P2  
- Delivered insights that supported visibility and content strategy improvements
